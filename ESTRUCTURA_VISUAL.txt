🚀 COMANDOS RÁPIDOS:

  Instalar:
    $ npm install

  Iniciar:
    $ npm start

  Verificar:
    $ ./scripts/verificar.sh

  Encontrar IP:
    $ ./scripts/find-ip.sh

  Ayuda:
    $ cat EMPEZAR_AQUI.md

═══════════════════════════════════════════════════════════════════

🔗 FLUJO DE USO:

  1. Lee EMPEZAR_AQUI.md
       ↓
  2. npm install
       ↓
  3. npm start
       ↓
  4. Abre http://localhost:3000
       ↓
  5. Conecta tu móvil (usa find-ip.sh)
       ↓
  6. Acepta permisos en ambos dispositivos
       ↓
  7. Haz clic en "Iniciar Rastreo"
       ↓
  8. ¡Disfruta viendo tus dispositivos en el mapa!
