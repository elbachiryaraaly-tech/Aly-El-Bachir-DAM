### 4️⃣ Ejemplos de Código

#### `hero-section-moderna.html`
Hero section lista para copiar y pegar con:
- 🎬 Video de fondo optimizado
- ✨ Gradientes y animaciones modernas
- 🔥 CTA con efecto "pulse"
- 📱 Totalmente responsive

**Cómo usar:**
1. Reemplaza el hero actual por este código
2. Añade tu video de gimnasio (máx 5MB)
3. Personaliza colores y texto

---

#### `estilos-modernos.css`
Sistema de diseño completo con:
- 🎨 Variables CSS (colores, espaciado, tipografía)
- 🪟 Glassmorphism y neumorphism
- 🔘 Botones modernos con efectos
- 💳 Tarjetas de precios optimizadas
- 📱 WhatsApp button flotante
- 🌓 Dark mode toggle
- ✨ Animaciones suaves

**Cómo usar:**
1. Incluir en el `<head>`:
   ```html
   <link rel="stylesheet" href="estilos-modernos.css">
   ```
2. Aplicar clases a elementos:
   ```html
   <div class="glass-card">...</div>
   <button class="btn-modern btn-primary">Click</button>
   ```

---

#### `schema-org-markup.html`
SEO avanzado con datos estructurados para:
- 🏢 LocalBusiness (información del gimnasio)
- ⭐ Reseñas y ratings
- 💰 Precios y planes
- 📍 Ubicación y horarios
- ❓ FAQ (preguntas frecuentes)

**Cómo usar:**
1. Copiar todo el contenido
2. Pegar en el `<head>` de la página principal
3. Personalizar datos (teléfono, dirección, coordenadas)
4. Verificar con: https://search.google.com/test/rich-results

**Resultado:** Rich snippets en Google con estrellas, horarios, y más

---

#### `manifest.json`
Configuración PWA para:
- 📱 Instalación como app nativa
- 🎨 Iconos en todas las plataformas
- 🚀 Shortcuts rápidos
- 📸 Screenshots para app stores

**Cómo usar:**
1. Copiar `manifest.json` a la raíz del sitio
2. Añadir en el `<head>`:
   ```html
   <link rel="manifest" href="/manifest.json">
   ```
3. Generar iconos con https://realfavicongenerator.net/

## 🚀 Cómo Empezar

### Opción A: Quick Wins (Tú mismo, 1 semana, gratis)

**Día 1: Limpieza técnica**
```html
<!-- 1. Eliminar de <head>: -->
<link rel="stylesheet" href=".../font-awesome/5.7.1/css/all.css"> ❌
<link rel="stylesheet" href=".../font-awesome/5.15.4/css/all.css"> ❌
<!-- Mantener solo: -->
<link rel="stylesheet" href=".../font-awesome/6.5.0/css/all.css"> ✅
```

**Día 2: WhatsApp flotante**
```html
<!-- Copiar antes de </body>: -->
<a href="https://wa.me/34XXXXXXXXX" class="whatsapp-float" target="_blank">
  <i class="fab fa-whatsapp"></i>
</a>
```

**Día 3-4: Optimizar imágenes**
```bash
cd wp-content/themes/lowgim-theme/assets/images
bash /ruta/a/optimizar-imagenes.sh
```

**Día 5: Schema.org**
- Copiar contenido de `schema-org-markup.html`
- Pegar en `<head>` del tema
- Personalizar datos

**Día 6-7: Hero section**
- Reemplazar hero actual por `hero-section-moderna.html`
- Añadir video de gimnasio
- Probar responsive

**✅ Resultado esperado:**
- +25% velocidad
