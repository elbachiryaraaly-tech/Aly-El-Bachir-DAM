# Proyecto de Geolocalización (Ejemplo Educativo)

Este proyecto demuestra cómo solicitar y obtener la ubicación de un usuario utilizando la API de Geolocalización del navegador web.

**Nota Importante sobre Privacidad:**
No es posible técnicamente ni legal obtener la ubicación de una persona únicamente a través de su número de teléfono sin su consentimiento explícito y sin acceso a sistemas de telecomunicaciones restringidos (que solo están disponibles para fuerzas de seguridad bajo orden judicial).

Este ejemplo muestra la única forma estándar y ética de obtener ubicación: **solicitando permiso al usuario en su dispositivo**.

## Cómo usar
Abra el archivo `index.html` en un navegador web. Se le pedirá permiso para compartir su ubicación.
