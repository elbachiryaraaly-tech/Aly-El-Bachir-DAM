# 🔐 Guía Completa de Ciberseguridad y Hacking Ético

> **"El conocimiento es poder, pero el conocimiento ético es responsabilidad"**

¡Bienvenido al camino para convertirte en un profesional de la ciberseguridad! Esta guía te llevará desde los fundamentos hasta técnicas avanzadas de hacking ético.

## 📚 Índice del Curso

### Nivel Principiante 🟢

   - Ética y legalidad
   - Conceptos básicos

   - Modelo OSI y TCP/IP
   - Protocolos de red

   - Comandos esenciales
   - Sistema de archivos
   - Permisos y usuarios
   - Bash scripting

### Nivel Intermedio 🟡
4. **[Programación para Hackers](./04-programacion/README.md)**
   - Python para ciberseguridad
   - Scripting de automatización
   - Desarrollo de herramientas

   - CTF (Capture The Flag)
   - Plataformas de práctica

```
Mes 1-2: Fundamentos + Linux + Redes básicas
```

## 📜 Certificaciones Recomendadas

### Para Empezar
- **CompTIA Security+** - Base sólida en seguridad
- **eJPT** (eLearnSecurity Junior Penetration Tester) - Entrada al pentesting

### Nivel Intermedio
- **CEH** (Certified Ethical Hacker)
- **OSCP** (Offensive Security Certified Professional) ⭐ La más valorada

### Avanzado
- **OSEP** (Offensive Security Experienced Penetration Tester)
- **OSCE** (Offensive Security Certified Expert)
