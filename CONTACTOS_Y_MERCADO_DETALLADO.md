## Plataformas de Venta - Guía Detallada

### eBay - La Más Accesible

#### Configuración Recomendada
```
Cuenta: Crear cuenta en ebay.es (España)
Tipo: Cuenta particular inicialmente, luego profesional
PayPal/Gestión de pagos: Vincular cuenta bancaria

Categoría: Coleccionables > Rocas, Fósiles, Minerales > Meteoritos
```

#### Estrategia de Precios en eBay
```
Para meteoritos SIN clasificar:
- Precio inicial: 50% del valor estimado
- Subasta de 7 días: Mejor para piezas únicas
- Compra inmediata: Para lotes o piezas comunes

Para meteoritos CLASIFICADOS:
- Precio fijo: 80-90% del valor de mercado
- Acepta ofertas: Sí, con mínimo del 70%
```

#### Tips para eBay
```
✓ Fotos profesionales (mínimo 8)
✓ Descripción detallada en inglés
✓ Incluir peso exacto y dimensiones
✓ Mencionar coordenadas aproximadas de hallazgo
✓ Especificar: "Unclassified NWA" si no está clasificado
✓ Ofrecer certificado de autenticidad propio
✓ Envío internacional con seguimiento
```

### Catawiki - Subastas Europeas

#### Proceso
```
1. Registrarse como vendedor en catawiki.com
2. Proponer lote con fotos y descripción
3. Experto de Catawiki evalúa y acepta/rechaza
4. Si acepta, se incluye en subasta semanal
5. Comisión: ~12.5% + costes de pago
```

#### Ventajas de Catawiki
- Audiencia europea cualificada
- Expertos que validan autenticidad
- Buenos precios para piezas interesantes
- Proceso más profesional que eBay

## Aspectos Logísticos Detallados

### Envío de Meteoritos

#### Envío Nacional (España)
```
Opciones:
- Correos (certificado con seguro)
- MRW, SEUR, DHL
- Para piezas valiosas: Seguro adicional

Empaquetado:
- Caja rígida
- Relleno abundante
- "FRÁGIL" visible
- Sin indicar contenido específico
```

#### Envío Internacional desde España
```
Para Europa:
- Correos certificado: 15-25€
- DHL/UPS: 30-60€
- Tiempo: 5-10 días

Para EE.UU.:
- Correos: 25-50€
- DHL/UPS: 60-120€
- Tiempo: 7-15 días

Documentación:
- Declaración aduanera CN23
- Describir como "piedra/mineral" (no "meteorito" para evitar problemas)
- Valor declarado (para seguro)
```

### Empaquetado Profesional
```
Materiales:
- Caja de cartón doble capa
- Plástico de burbujas
- Espuma
- Papel de seda (para corteza de fusión delicada)
- Bolsa ziplock (previene humedad)

Proceso:
1. Envolver piedra en papel de seda
2. Colocar en bolsa ziplock
3. Envolver en plástico de burbujas (2+ capas)
4. Colocar en caja con espuma/relleno
5. La piedra no debe moverse nada
6. Cerrar y etiquetar
```

## Modelo de Negocio Sugerido

### Opción A: Venta Directa Minorista
```
Ventajas:
- Mayor margen por pieza
- Control del proceso

Desventajas:
- Más tiempo requerido
- Necesita reputación
- Riesgo de devoluciones

Margen típico: 100-300%
```

### Opción B: Venta a Mayoristas/Dealers
```
Ventajas:
- Venta rápida en cantidad
- Sin gestión minorista
- Pago inmediato

Desventajas:
- Menor precio por pieza
- Dependencia de pocos compradores

Margen típico: 30-100%
```

### Opción C: Modelo Híbrido (Recomendado)
```
1. Seleccionar las MEJORES piezas para clasificar y vender retail
2. Vender el material común a mayoristas
3. Usar fotos de buenas piezas para marketing
4. Reinvertir beneficios en clasificación

Este es el modelo que usan la mayoría de dealers exitosos.
```

## Checklist Final

### Antes de Intentar Vender

```
☐ Todas las piezas probadas (imán, densidad, raya)
☐ Documentación fotográfica completa
☐ Peso exacto de cada pieza
☐ Opiniones preliminares obtenidas online
☐ Al menos 1-2 piezas identificadas como probables meteoritos
☐ Plan para transportar material legalmente
☐ Cuenta bancaria para recibir pagos
☐ Decisión sobre clasificación (sí/no, cuáles)
```

### Antes de Clasificación

```
☐ Pieza confirmada como probable meteorito por expertos
☐ Peso suficiente para sacrificar muestra
☐ Presupuesto disponible (500€-2000€)
☐ Laboratorio contactado y aceptado
☐ Método de envío organizado
```

### Antes de Vender Retail

```
☐ Fotos profesionales de cada pieza
☐ Descripciones escritas en inglés
☐ Cuenta en plataforma de venta (eBay, etc.)
☐ Sistema de envío preparado
☐ Política de devoluciones definida
☐ Precios investigados y fijados
```
