# 🇩🇿 SUPER MEGA PROMPT - PÁGINA WEB ÉLITE CONSULADO DE ARGELIA EN ALICANTE

## INSTRUCCIÓN PRINCIPAL

Construye una página web **ULTRA PROFESIONAL, MODERNA y de ÉLITE** para el **Consulado de Argelia en Alicante**. Debe ser la página web gubernamental más impresionante, con diseño de clase mundial, animaciones fluidas, accesibilidad perfecta, SEO optimizado y experiencia de usuario excepcional.

---

## 🛠️ STACK TECNOLÓGICO OBLIGATORIO

```
- Framework: Next.js 14+ (App Router)
- Lenguaje: TypeScript (estricto)
- Estilos: Tailwind CSS 3.4+
- Animaciones: Framer Motion
- Iconos: Lucide React + Heroicons
- Fuentes: Inter + Noto Sans Arabic (Google Fonts)
- Formularios: React Hook Form + Zod
- Internacionalización: next-intl (Español, Francés, Árabe)
- UI Components: Radix UI primitives
- Maps: Leaflet o Google Maps embed
- Deployment ready: Vercel
```
