# 🌟 SUPER MEGA PROMPT - YARALUXE 🌟

Crea una tienda online de lujo revolucionaria llamada **YaraLuxe** para dropshipping automático de productos premium (perfumes, accesorios de lujo, joyería, relojes, productos de cuidado personal exclusivos).

## 🎯 OBJETIVO PRINCIPAL
Construir una plataforma e-commerce que supere a las mejores tiendas de Shopify por años luz en diseño, funcionalidad, automatización y experiencia de usuario. Debe ser tan impresionante que parezca hecha por una agencia de diseño de élite con presupuesto ilimitado.

## 🛠️ STACK TECNOLÓGICO OBLIGATORIO

### Frontend
- **Next.js 14+** (App Router) con TypeScript
- **React 18+** con Server Components
- **Tailwind CSS** + **Framer Motion** para animaciones cinematográficas
- **Radix UI** o **Shadcn/ui** para componentes accesibles
- **GSAP** para animaciones avanzadas de scroll
- **Three.js** o **React Three Fiber** para efectos 3D sutiles
- **Swiper** para carruseles premium
- **React Hook Form** + **Zod** para validación

### Backend & Base de Datos
- **Next.js API Routes** o **tRPC** para APIs type-safe
- **Prisma** como ORM
- **PostgreSQL** o **Supabase** para base de datos
- **NextAuth.js** para autenticación completa (OAuth + Email)
- **Stripe** o **PayPal** para pagos
- **Resend** o **SendGrid** para emails transaccionales

### Dropshipping & Automatización
- **AliExpress API** o **Oberlo/Spocket API** para productos
- **Webhooks** para sincronización automática de inventario
- **Bull** o **BullMQ** para colas de trabajos
- **Shopify Admin API** (solo para importar productos si es necesario)
- **Printful API** o **CJDropshipping API** como alternativas

### Almacenamiento & CDN
- **Cloudinary** o **Vercel Blob** para imágenes optimizadas
- **AWS S3** como alternativa
- CDN automático para carga ultra-rápida

### Analíticas & SEO
- **Google Analytics 4** integrado
- **Meta Pixel** (Facebook/Instagram)
- **TikTok Pixel**
- **Next.js SEO** con metadata dinámica
- **JSON-LD** para rich snippets
- **Sitemap** y **robots.txt** automáticos

**Gestión de Productos AUTOMÁTICA**:
- **Importación masiva desde AliExpress/CJDropshipping**:
  - Pegar URL o ID del producto → Importa automáticamente
  - Extrae: título, descripción, imágenes, variantes, precios
  - Aplica markup automático (ej: +80% del precio original)
  - Traduce descripciones a español (OpenAI API)
  - Optimiza SEO automáticamente
  
- **Sincronización de Inventario**:
  - Webhook que actualiza stock cada hora
  - Desactiva productos sin stock automáticamente
  - Notificación si un producto ya no está disponible
  
- **Precios Dinámicos**:
  - Reglas: margen %, precio fijo, descuentos por cantidad
  - Precios de oferta con temporizador automático
  
- **Editor Visual**:
  - Arrastrar y soltar imágenes
  - Editor WYSIWYG para descripciones
  - Generador de variantes automático

**Gestión de Pedidos SIN INTERVENCIÓN**:
- Cliente compra → Sistema crea orden en YaraLuxe
- **Automatización**:
  1. Pedido se reenvía automáticamente al proveedor (API)
  2. Sistema paga al proveedor con cuenta configurada
  3. Proveedor envía directo al cliente
  4. Tracking number se sincroniza automáticamente
  5. Email de confirmación + tracking enviado al cliente
  6. Cuando llega: Email de seguimiento post-venta
  
- **Panel de Pedidos**:
  - Estados: Pendiente, Pagado, Enviado, Entregado, Cancelado
  - Filtros avanzados y búsqueda
  - Exportar a CSV/Excel
  - Imprimir etiquetas de envío (si es necesario)
  - Reembolsos con un click

   npm install prisma @prisma/client
   npm install framer-motion clsx tailwind-merge
   npm install @radix-ui/react-dialog @radix-ui/react-dropdown-menu
   npm install stripe @stripe/stripe-js
   npm install next-auth
   npm install react-hook-form zod @hookform/resolvers
   npm install resend
   npm install recharts
   npm install swiper
   npm install lucide-react
