## 🎯 FACTORES QUE AFECTAN EL PRECIO

### 1. Tipo de Meteorito (Factor Más Importante)

**Impacto en precio**: ⭐⭐⭐⭐⭐ (Muy Alto)

- Condritas ordinarias: €0.10-2/g
- Condritas carbonáceas: €5-100/g (50-500x más)
- Meteoritos lunares: €500-5,000/g (2,500-25,000x más)
- Meteoritos marcianos: €1,000-10,000/g (5,000-50,000x más)

### 2. Tamaño y Peso

**Impacto en precio**: ⭐⭐⭐⭐ (Alto)

| Tamaño | Factor de Precio |
|--------|------------------|
| **<10g** (fragmentos) | Precio base |
| **10-50g** | Precio base |
| **50-100g** | Precio base +10-20% |
| **100-500g** | Precio base +20-50% |
| **>500g** | Precio base +50-100% |

**Ejemplo**: 
- 10g de condrita: €5-10
- 100g de condrita: €50-120 (no solo 10x más)

### 3. Condición y Calidad

**Impacto en precio**: ⭐⭐⭐⭐ (Alto)

| Condición | Factor de Precio |
|-----------|------------------|
| **Excelente** (corteza intacta, sin oxidación) | Precio base +50-100% |
| **Buena** (corteza parcial, mínima oxidación) | Precio base |
| **Regular** (sin corteza, algo oxidado) | Precio base -30-50% |
| **Mala** (muy oxidado, erosionado) | Precio base -50-80% |

### 4. Certificación Oficial

**Impacto en precio**: ⭐⭐⭐⭐⭐ (Crítico)

| Estado de Certificación | Factor de Precio |
|------------------------|------------------|
| **Sin certificación** | €0.01-0.10/g (casi sin valor) |
| **Certificado oficial** | Precio base completo |
| **Certificado + procedencia** | Precio base +10-30% |

**Ejemplo**:
- Sin certificar: €5-20 total
- Certificado: €50-200 (10x más)

### 5. Preparación y Presentación

**Impacto en precio**: ⭐⭐⭐ (Medio)

| Preparación | Factor de Precio |
|-------------|------------------|
| **Sin preparar** (crudo) | Precio base |
| **Corte pulido** | Precio base +20-50% |
| **Corte pulido + etiqueta profesional** | Precio base +30-70% |
| **Montado en display** | Precio base +50-100% |

### 6. Rareza y Procedencia

**Impacto en precio**: ⭐⭐⭐⭐ (Alto)

- Meteoritos de caídas observadas: +20-50%
- Meteoritos de localidades famosas: +10-30%
- Meteoritos con historia documentada: +15-40%
- Nuevos tipos de meteoritos: +50-200%

### 7. Forma y Estética

**Impacto en precio**: ⭐⭐⭐ (Medio)

- Forma aerodinámica interesante: +10-30%
- Regmaglypts (huellas de pulga) visibles: +15-25%
- Cóndrulos bien visibles: +20-40%
- Estructura Widmanstätten visible: +30-60%

## 💰 CÁLCULO DEL VALOR POTENCIAL

### Fórmula Básica de Valoración

```
Valor Base = Peso (g) × Precio por gramo (según tipo)

Valor Final = Valor Base × Factor de Tamaño × Factor de Condición 
              × Factor de Certificación × Factor de Preparación
```

### Ejemplo de Cálculo

**Escenario**: Tienes 200g de condrita ordinaria certificada en buena condición

1. **Valor base**: 200g × €0.60/g = €120
2. **Factor tamaño** (200g): +20% = €144
3. **Factor condición** (buena): ×1.0 = €144
4. **Factor certificación** (certificado): ×1.0 = €144
5. **Factor preparación** (sin preparar): ×1.0 = €144

**Valor estimado**: €120-180

### Ejemplo con Meteorito Más Valioso

**Escenario**: Tienes 50g de condrita carbonácea certificada en excelente condición

1. **Valor base**: 50g × €40/g = €2,000
2. **Factor tamaño** (50g): ×1.0 = €2,000
3. **Factor condición** (excelente): +50% = €3,000
4. **Factor certificación** (certificado): ×1.0 = €3,000
5. **Factor preparación** (corte pulido): +30% = €3,900

**Valor estimado**: €3,000-4,500
