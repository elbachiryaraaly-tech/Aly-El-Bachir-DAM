```

```
Crea una aplicación web completa para [descripción del SaaS].
Stack: Next.js + Tailwind + PostgreSQL + Stripe.
Incluye: autenticación, dashboard de usuario, planes de suscripción,
panel de administración, y landing page de ventas.
```

### Para Automatizaciones:
```
Crea un bot que [acción específica] usando la API de [servicio].
Incluye: manejo de errores, logging, notificaciones por email/Telegram,
y documentación de uso.
```

```
Crea un pipeline de datos que extraiga información de [fuentes],
la procese con pandas, genere visualizaciones con plotly,
y envíe un reporte semanal por email.
