┌───────────────────────────────────────────────────────────────┐
│  🚀 INICIO RÁPIDO (3 PASOS)                                   │
└───────────────────────────────────────────────────────────────┘

  1️⃣  Instalar dependencias:
      $ npm install

  2️⃣  Iniciar servidor:
      $ npm start

  3️⃣  Abrir en navegadores:
      → Ordenador: http://localhost:3000
      → Móvil: http://[IP-LOCAL]:3000


┌───────────────────────────────────────────────────────────────┐
│  📱 CONECTAR MÓVIL Y ORDENADOR                                │
└───────────────────────────────────────────────────────────────┘

  En tu ORDENADOR:
  ─────────────────
  1. Ejecuta: npm start
  2. Abre: http://localhost:3000
  3. Anota tu IP local

  En tu MÓVIL:
  ────────────
  1. Conecta a la misma WiFi que el ordenador
  2. Abre el navegador
  3. Visita: http://[IP-DEL-ORDENADOR]:3000


┌───────────────────────────────────────────────────────────────┐
│  🔧 ENCONTRAR TU IP LOCAL                                     │
└───────────────────────────────────────────────────────────────┘

  Automático:
      $ ./scripts/find-ip.sh

  Manual:
      Linux/Mac: ifconfig | grep inet
      Windows:   ipconfig


┌───────────────────────────────────────────────────────────────┐
│  💡 CONSEJOS PARA MÁXIMA PRECISIÓN                           │
└───────────────────────────────────────────────────────────────┘

  ✓ Activa el GPS en tu móvil
  ✓ Activa el WiFi (ayuda a triangulación)
  ✓ Sal al exterior si la precisión es baja
  ✓ Espera 10-15 seg para que se estabilice
  ✓ Acepta los permisos de ubicación
