# 🔬 Pasos Prácticos para Identificar tus Piedras

## Antes de Empezar: ¿Qué NO son meteoritos?

El 99% de las piedras que la gente cree que son meteoritos NO lo son. Los "meteorwrongs" más comunes son:

### Rocas Terrestres Confundidas Frecuentemente

| Roca | Por qué confunde | Cómo diferenciar |
|------|------------------|------------------|
| **Magnetita** | Muy magnética, negra | Deja raya negra en porcelana, muy brillante |
| **Hematita** | Pesada, oscura | Deja raya roja/marrón, no magnética |
| **Escoria industrial** | Aspecto fundido, pesada | Tiene burbujas, muy porosa |
| **Nódulos de hierro** | Pesados, magnéticos | Interior oxidado uniforme, sin metal brillante |
| **Basalto** | Oscuro, denso | Tiene burbujas, cristales visibles de feldespato |
| **Limonita/Goethita** | Aspecto metálico | Muy ligera para su tamaño, amarillenta al raspar |
| **Pirita** | Brillo metálico | Color dorado, cristales cúbicos, raya verdosa |

## Paso 1: Prueba del Imán (5 minutos)

### Materiales
- Imán de neodimio (recomendado, muy fuerte)
- O imán de nevera (menos sensible)

### Procedimiento
1. Limpia la piedra de polvo y arena
2. Acerca el imán a diferentes partes
3. Prueba tanto la superficie como bordes

### Resultados

| Resultado | Interpretación | Siguiente paso |
|-----------|----------------|----------------|
| **Atracción muy fuerte** (imán se pega solo) | Posible meteorito metálico o condrita rica en hierro | Continuar pruebas ✓ |
| **Atracción moderada** (se nota tirón) | Posible condrita | Continuar pruebas ✓ |
| **Atracción débil** (apenas perceptible) | Podría ser acondrita (raro) o no meteorito | Continuar con precaución |
| **Sin atracción** | Probablemente NO meteorito, PERO acondritas (lunares/marcianas) no son magnéticas | Si tiene otras características, continuar |

---

## Paso 2: Inspección Visual Detallada (15 minutos)

### Materiales
- Lupa 10x o 20x (o zoom de cámara del móvil)
- Buena iluminación
- Agua para limpiar

### Qué Buscar

#### A) Corteza de Fusión
```
Ubicación: Superficie exterior
Aspecto: Capa negra/marrón oscuro de ~1mm
Textura: Mate, a veces brillante, puede estar agrietada

✓ POSITIVO: Capa uniforme oscura que cubre toda la piedra
✗ NEGATIVO: Color irregular, brillo metálico, superficie pulida naturalmente
```

#### B) Regmagliptos ("Huellas de pulgar")
```
Ubicación: Superficie exterior
Aspecto: Pequeñas depresiones redondeadas
Tamaño: 0.5 - 3 cm típicamente

✓ POSITIVO: Depresiones suaves, como si alguien hubiera apretado arcilla
✗ NEGATIVO: Agujeros profundos, burbujas, poros (indica roca volcánica)
```

#### C) Interior (si hay algún corte o fractura visible)
```
✓ POSITIVO para meteorito:
- Granos metálicos brillantes distribuidos
- Pequeñas esferas (cóndrulos) de diferentes colores
- Textura homogénea sin capas
- Color gris con puntos metálicos

✗ NEGATIVO:
- Cristales grandes y definidos
- Capas o estratos
- Burbujas o huecos
- Color uniforme sin inclusiones metálicas
```

## Paso 3: Prueba de Densidad (10 minutos)

### Materiales
- Balanza de cocina (precisión 1g mínimo, mejor 0.1g)
- Vaso o recipiente
- Agua
- Hilo o cuerda fina

### Procedimiento Detallado

```
MÉTODO DE DESPLAZAMIENTO DE AGUA:

1. Pesa la piedra seca → Anota como PESO SECO (M)

2. Llena el vaso hasta un nivel marcado

3. Ata la piedra con el hilo y sumérgela completamente

4. Mide el agua desplazada en ml (o pesa el vaso antes/después)
   El volumen en ml = volumen en cm³ (V)

5. Calcula: DENSIDAD = M / V

Ejemplo:
- Piedra pesa 150 gramos
- Desplaza 45 ml de agua
- Densidad = 150/45 = 3.33 g/cm³
```

### Interpretación de Resultados

| Densidad (g/cm³) | Interpretación |
|------------------|----------------|
| **7.0 - 8.0** | ¡Muy probable meteorito metálico! |
| **4.5 - 6.0** | Posible meteorito hierro-piedra (pallasito) |
| **3.3 - 3.8** | Posible condrita ✓ |
| **3.0 - 3.3** | Posible acondrita |
| **2.6 - 3.0** | Probablemente roca terrestre (basalto, etc.) |
| **< 2.6** | NO es meteorito (demasiado ligero) |

---

## Paso 4: Prueba de la Raya (5 minutos)

### Materiales
- Plato de porcelana sin esmaltar (parte trasera de un azulejo)
- O trozo de cerámica sin vidriar

### Procedimiento
1. Frota la piedra firmemente contra la porcelana
2. Observa el color del polvo dejado

### Resultados

| Color de Raya | Significado |
|---------------|-------------|
| **Negra intensa** | Magnetita - NO es meteorito |
| **Roja/Marrón rojiza** | Hematita - NO es meteorito |
| **Amarilla/Ocre** | Limonita/Goethita - NO es meteorito |
| **Verdosa** | Posible pirita o clorita - NO es meteorito |
| **Gris muy tenue o sin raya** | POSITIVO - El hierro-níquel meteórico no deja raya |

---

## Paso 5: Prueba de la Ventana (Opcional pero útil)

### Materiales
- Lima de metal o piedra de amolar
- Agua para enfriar
- Lupa

### Procedimiento
```
⚠️ CUIDADO: Esta prueba es ligeramente destructiva
   Solo hacerla en una esquina poco visible

1. Lima una pequeña área (5mm x 5mm) hasta exponer interior
2. Pule con lija fina (400-600)
3. Limpia con agua
4. Observa con lupa
```

### Qué Buscar en la "Ventana"

| Observación | Significado |
|-------------|-------------|
| **Puntos brillantes metálicos distribuidos** | ✓ Probable meteorito - granos de hierro-níquel |
| **Pequeñas esferas de colores** | ✓ Cóndrulos - definitivamente meteorito (condrita) |
| **Metal continuo brillante** | ✓ Probable meteorito metálico |
| **Óxido marrón/naranja uniforme** | ✗ Oxidación terrestre - probablemente no meteorito |
| **Cristales grandes y transparentes** | ✗ Mineral terrestre |
| **Burbujas o huecos** | ✗ Roca volcánica |

## Paso 6: Documentación Fotográfica

### Configuración
```
- Luz: Natural, día nublado ideal (sin sombras duras)
- Fondo: Blanco, negro o gris neutro
- Escala: Regla o moneda conocida en cada foto
- Cámara: Móvil con buena cámara está bien
```

### Fotos Necesarias (mínimo 8 por pieza)

1. **Vista superior** con escala
2. **Vista inferior** con escala
3. **Vista lateral 1** con escala
4. **Vista lateral 2** con escala
5. **Detalle de corteza de fusión** (macro/zoom)
6. **Detalle de regmagliptos** si los hay
7. **Foto con imán** mostrando atracción
8. **Detalle de interior** si hay corte o fractura

### Información a Documentar

```
Para cada pieza, anota:

IDENTIFICACIÓN:
- Número de pieza: ___
- Peso exacto: ___ gramos
- Dimensiones: ___ x ___ x ___ cm

CARACTERÍSTICAS:
- Resultado prueba imán: ___
- Densidad calculada: ___ g/cm³
- Color de raya: ___
- Corteza de fusión: Sí/No/Parcial
- Regmagliptos: Sí/No

HALLAZGO:
- Fecha de hallazgo: ___
- Ubicación exacta: ___
- Coordenadas GPS (si es posible): ___

_________________________________
```

## Paso 8: Evaluación de Resultados

### Tabla de Puntuación

Suma los puntos según tus resultados:

| Característica | Puntos |
|----------------|--------|
| Atracción magnética fuerte | +3 |
| Atracción magnética moderada | +2 |
| Densidad > 3.3 g/cm³ | +3 |
| Corteza de fusión presente | +3 |
| Regmagliptos visibles | +2 |
| Sin burbujas ni poros | +2 |
| Granos metálicos en interior | +3 |
| Cóndrulos visibles | +5 |
| Raya tenue o ausente | +1 |
| --- | --- |
| Raya negra o roja | -5 |
| Burbujas o poros | -5 |
| Cristales grandes visibles | -3 |
| Muy ligera (densidad < 2.8) | -5 |
| Capas o estratos | -4 |

### Interpretación

| Puntuación | Conclusión |
|------------|------------|
| **15+** | ¡Muy probablemente es meteorito! Buscar clasificación oficial |
| **10-14** | Prometedor, vale la pena investigar más |
| **5-9** | Dudoso, pedir más opiniones |
| **0-4** | Probablemente no es meteorito |
| **Negativo** | Casi seguro que NO es meteorito |

## Próximos Pasos Según Resultado

### Si la puntuación es 10+

1. ✅ Completar documentación fotográfica profesional
2. ✅ Buscar opiniones en foros especializados
3. ✅ Contactar dealers para evaluación preliminar
4. ✅ Considerar envío de muestra para clasificación

### Si la puntuación es 5-9

1. ⚠️ Buscar más opiniones antes de gastar dinero
2. ⚠️ No enviar para clasificación todavía
3. ⚠️ Considerar que hay 50% de probabilidad de que no sea meteorito

### Si la puntuación es < 5

1. ❌ Probablemente no vale la pena invertir más
2. ❌ Pero si tienes muchas piezas, seleccionar las mejores
3. ❌ Las rocas terrestres del Sahara también pueden ser interesantes

---

*Recuerda: Estos tests son preliminares. Solo un análisis de laboratorio puede confirmar definitivamente si una piedra es un meteorito.*
