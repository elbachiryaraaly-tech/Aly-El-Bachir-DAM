## 🎯 LOS 5 PASOS ESENCIALES

### PASO 1: VERIFICAR (Antes de todo lo demás)
```
Tiempo: 1-2 semanas
Coste: ~0€ (pruebas caseras) + ~0€ (consultas online)

Acciones:
1. Prueba del imán → ¿Hay atracción?
2. Prueba de densidad → ¿Más de 3.3 g/cm³?
3. Inspección visual → ¿Corteza de fusión? ¿Sin burbujas?
4. Fotografiar todo profesionalmente
5. Publicar en Reddit r/meteorites o grupos de Facebook

Resultado esperado: Saber si vale la pena continuar
```

### PASO 2: TRANSPORTAR A ESPAÑA
```
Tiempo: Variable
Coste: Billete de avión

⚠️ REALIDAD LEGAL:
- Argelia prohíbe exportación de meteoritos
- Riesgo en aduanas argelinas
- España no tiene restricciones

ESTRATEGIA RECOMENDADA:
- Cantidades pequeñas (1-3 kg máximo)
- En equipaje personal
- Mezclado con otros minerales/recuerdos
- Discretamente, sin documentar como "meteoritos"
```

### PASO 3: CLASIFICAR (Opcional pero muy rentable)
```
Tiempo: 6-12 meses
Coste: 500€ - 2,000€

Por qué hacerlo:
- Multiplica el valor x5 a x10
- Permite vender a museos y coleccionistas serios
- Da nombre oficial al meteorito

Cuándo NO hacerlo:
- Material muy común/oxidado
- Cantidad pequeña de material mediocre
- Presupuesto muy limitado
```

### PASO 4: VENDER
```
Tiempo: 1-6 meses por pieza
Coste: Comisiones de venta (10-15%)

CANALES PRINCIPALES:
1. eBay (más accesible, audiencia global)
2. Catawiki (subastas europeas)
3. Dealers directos (venta rápida, menor precio)
4. Ferias (networking + ventas)
```

### PASO 5: GESTIONAR FISCALMENTE
```
En España:
- Declarar ventas en IRPF
- Si actividad regular: Considerar autónomo
```

## 💰 EXPECTATIVAS DE PRECIO

### Material SIN Clasificar

| Tipo | Precio/kg |
|------|-----------|
| Condrita común, mala condición | 100€ - 300€ |
| Condrita común, buena condición | 300€ - 800€ |
| Condrita con buena corteza | 800€ - 2,000€ |

### Material CLASIFICADO

| Tipo | Precio/gramo |
|------|--------------|
| Condrita ordinaria | 1€ - 5€ |
| Condrita rara (carbonácea, etc.) | 10€ - 100€ |
| Lunar (si tienes MUCHA suerte) | 500€ - 1,500€ |
| Marciano (extremadamente raro) | 500€ - 2,000€ |

### Ejemplo Práctico
```
Tienes: 5 kg de condritas comunes en buena condición

Sin clasificar:
- Valor: 1,500€ - 4,000€

Si clasificas 1 kg:
- Coste clasificación: ~800€
- Valor 1 kg clasificado: 3,000€ - 5,000€
- Valor 4 kg sin clasificar: 1,200€ - 3,200€
- Total: 4,200€ - 8,200€ (menos coste = 3,400€ - 7,400€)
```

## ⚠️ RIESGOS PRINCIPALES

### Riesgo 1: No son meteoritos
```
Probabilidad: ALTA (90% de "meteoritos" son meteorwrongs)
Mitigación: Pruebas caseras + opinión experta ANTES de gastar dinero
```

### Riesgo 2: Problemas en aduana argelina
```
Probabilidad: MEDIA (depende de cantidad y suerte)
Mitigación: Cantidades pequeñas, discreción, mezclar con otros objetos
Consecuencia: Confiscación, posible multa
```

### Riesgo 3: Material de poco valor
```
Probabilidad: MEDIA-ALTA
Realidad: La mayoría de meteoritos del Sahara son condritas comunes
Mitigación: Buscar piezas con características especiales
```

### Riesgo 4: Estafas al vender
```
Probabilidad: BAJA-MEDIA
Mitigación: Usar plataformas con protección, verificar compradores
```
