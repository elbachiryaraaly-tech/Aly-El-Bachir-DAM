# 📖 Glosario de Ciberseguridad

## A

**ARP (Address Resolution Protocol)**
Protocolo que traduce direcciones IP a direcciones MAC en una red local.

**APT (Advanced Persistent Threat)**
Ataque sofisticado y prolongado, generalmente patrocinado por estados.

**Authentication**
Proceso de verificar la identidad de un usuario o sistema.

**Authorization**
Proceso de determinar qué acciones puede realizar un usuario autenticado.

---

## B

**Backdoor**
Método oculto para eludir la autenticación normal y obtener acceso a un sistema.

**Banner Grabbing**
Técnica para obtener información sobre servicios conectándose a sus puertos.

**Black Hat**
Hacker que realiza actividades maliciosas o ilegales.

**Blue Team**
Equipo defensivo encargado de proteger los sistemas.

**Botnet**
Red de dispositivos infectados controlados remotamente.

**Brute Force**
Ataque que prueba todas las combinaciones posibles hasta encontrar la correcta.

**Buffer Overflow**
Vulnerabilidad donde se escribe más datos de los que un buffer puede contener.

**Bug Bounty**
Programa donde empresas pagan por reportes de vulnerabilidades.

---

## C

**C2 (Command and Control)**
Servidor usado para controlar sistemas comprometidos.

**CIA Triad**
Confidencialidad, Integridad y Disponibilidad - pilares de la seguridad.

**CSRF (Cross-Site Request Forgery)**
Ataque que engaña al navegador para realizar acciones no autorizadas.

**CTF (Capture The Flag)**
Competición de seguridad donde se resuelven desafíos.

**CVE (Common Vulnerabilities and Exposures)**
Sistema de identificación única para vulnerabilidades.

**CVSS (Common Vulnerability Scoring System)**
Sistema de puntuación de gravedad de vulnerabilidades (0-10).

---

## D

**DDoS (Distributed Denial of Service)**
Ataque que satura un servicio con tráfico desde múltiples fuentes.

**DMZ (Demilitarized Zone)**
Subred que expone servicios externos aislados de la red interna.

**DNS (Domain Name System)**
Sistema que traduce nombres de dominio a direcciones IP.

**DoS (Denial of Service)**
Ataque que hace que un servicio no esté disponible.

**Doxing**
Revelar información privada de una persona públicamente.

---

## E

**Encryption**
Proceso de codificar información para que solo usuarios autorizados puedan leerla.

**Enumeration**
Proceso de extraer información detallada de un sistema (usuarios, servicios, etc.).

**Exploit**
Código que aprovecha una vulnerabilidad.

**Exfiltration**
Extracción no autorizada de datos de un sistema.

---

## F

**Firewall**
Sistema que filtra el tráfico de red basado en reglas.

**Footprinting**
Recopilación de información sobre un objetivo antes de un ataque.

**Forensics**
Análisis de evidencia digital para investigar incidentes de seguridad.

**FTP (File Transfer Protocol)**
Protocolo para transferir archivos (puerto 21).

---

## G

**Grey Hat**
Hacker que opera entre lo legal e ilegal, generalmente sin malas intenciones.

---

## H

**Hash**
Función que convierte datos en una cadena de longitud fija (MD5, SHA256).

**Honeypot**
Sistema señuelo diseñado para atraer atacantes y estudiar sus técnicas.

**HTTP/HTTPS**
Protocolo de transferencia de hipertexto (puerto 80/443).

---

## I

**IDS (Intrusion Detection System)**
Sistema que detecta actividad sospechosa en la red.

**IPS (Intrusion Prevention System)**
Sistema que detecta Y bloquea actividad sospechosa.

**IDOR (Insecure Direct Object Reference)**
Vulnerabilidad donde se puede acceder a objetos cambiando identificadores.

---

## K

**Keylogger**
Software/hardware que registra las teclas presionadas.

**Kill Chain**
Modelo que describe las fases de un ciberataque.

---

## L

**LFI (Local File Inclusion)**
Vulnerabilidad que permite incluir archivos locales del servidor.

**Lateral Movement**
Técnica para moverse entre sistemas dentro de una red comprometida.

---

## M

**MAC Address**
Identificador único de hardware de una interfaz de red.

**Malware**
Software malicioso (virus, troyanos, ransomware, etc.).

**Man-in-the-Middle (MitM)**
Ataque donde el atacante intercepta comunicaciones entre dos partes.

**Metasploit**
Framework de pentesting con exploits y herramientas.

---

## N

**NAT (Network Address Translation)**
Técnica que permite a múltiples dispositivos compartir una IP pública.

**Nmap**
Herramienta de escaneo de redes y puertos.

**NTLM**
Protocolo de autenticación de Windows.

---

## O

**OSINT (Open Source Intelligence)**
Recopilación de información de fuentes públicas.

**OWASP**
Organización que promueve la seguridad en aplicaciones web.

---

## P

**Payload**
Código que se ejecuta después de explotar una vulnerabilidad.

**Pentesting (Penetration Testing)**
Pruebas de seguridad autorizadas para encontrar vulnerabilidades.

**Phishing**
Técnica de ingeniería social usando comunicaciones falsas.

**Pivot**
Usar un sistema comprometido para acceder a otros sistemas.

**Port**
Número que identifica un servicio específico (1-65535).

**Privilege Escalation**
Obtener mayores permisos de los que se tenían inicialmente.

**Proxy**
Intermediario entre cliente y servidor.

---

## R

**Rainbow Table**
Tabla precalculada de hashes para crackear contraseñas.

**Ransomware**
Malware que cifra archivos y exige rescate.

**RAT (Remote Access Trojan)**
Troyano que permite control remoto del sistema infectado.

**RCE (Remote Code Execution)**
Capacidad de ejecutar código de forma remota en un sistema.

**Reconnaissance (Recon)**
Fase de recopilación de información sobre el objetivo.

**Red Team**
Equipo que simula ataques reales contra una organización.

**Reverse Shell**
Shell donde el objetivo se conecta al atacante.

**RFI (Remote File Inclusion)**
Vulnerabilidad que permite incluir archivos remotos.

**Root**
Usuario con máximos privilegios en Linux/Unix.

**Rootkit**
Malware diseñado para ocultar su presencia en el sistema.

---

## S

**Sanitization**
Proceso de limpiar/validar input del usuario.

**Shell**
Interfaz de línea de comandos.

**Shodan**
Motor de búsqueda de dispositivos conectados a Internet.

**SMB (Server Message Block)**
Protocolo de compartición de archivos de Windows (puerto 445).

**Sniffing**
Captura de tráfico de red.

**Social Engineering**
Manipulación psicológica para obtener información o acceso.

**Spoofing**
Falsificar la identidad (IP, MAC, email, etc.).

**SQL Injection (SQLi)**
Inyección de código SQL malicioso en aplicaciones.

**SSH (Secure Shell)**
Protocolo seguro para acceso remoto (puerto 22).

**SSRF (Server-Side Request Forgery)**
Atacque que hace que el servidor realice peticiones no autorizadas.

**SSL/TLS**
Protocolos de encriptación para comunicaciones seguras.

**SUID**
Permiso especial que ejecuta un archivo como su propietario.

---

## T

**TCP (Transmission Control Protocol)**
Protocolo de transporte confiable y orientado a conexión.

**Threat Actor**
Individuo o grupo que realiza actividades maliciosas.

**Token**
Credencial de autenticación, generalmente temporal.

**Trojan**
Malware disfrazado de software legítimo.

---

## U

**UDP (User Datagram Protocol)**
Protocolo de transporte rápido pero no confiable.

---

## V

**VPN (Virtual Private Network)**
Red privada virtual que encripta el tráfico.

**Vulnerability**
Debilidad en un sistema que puede ser explotada.

---

## W

**WAF (Web Application Firewall)**
Firewall especializado en proteger aplicaciones web.

**White Hat**
Hacker ético que trabaja dentro de la legalidad.

**Wireshark**
Analizador de protocolos de red.

**Worm**
Malware que se propaga automáticamente por la red.

---

## X

**XSS (Cross-Site Scripting)**
Inyección de scripts maliciosos en páginas web.

**XXE (XML External Entity)**
Ataque que explota procesadores XML vulnerables.

---

## Z

**Zero-Day (0-day)**
Vulnerabilidad desconocida sin parche disponible.

**Zombie**
Dispositivo infectado parte de una botnet.

---

> *Este glosario se actualiza constantemente con nuevos términos.*
