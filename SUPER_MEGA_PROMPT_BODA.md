# PROMPT PARA CREAR PÁGINA WEB DE BODA DE NIVEL ELITE

Créame una página web de boda absolutamente ESPECTACULAR y de NIVEL ELITE para la boda que se celebrará el **10 de octubre de 2026**. Esta debe ser la página de boda más impresionante, elegante y funcional jamás creada. Quiero que cuando los invitados entren, sientan una EMOCIÓN INMENSA y mucha ilusión.

## 🎨 PALETA DE COLORES Y ESTILO

### Colores Principales:
- **Verde Eucalipto**: #5C7C6E, #6B8E7D, #7A9F8C (gradientes sutiles)
- **Blanco Roto/Crema**: #FAF9F6, #F5F5F0, #FFFEF9
- **Acentos dorados sutiles**: #D4AF37, #C9A962 (para detalles elegantes)
- **Grises suaves**: #8B8B8B, #A9A9A9 (para textos secundarios)

### Estilo Visual:
- Diseño minimalista pero LUJOSO y sofisticado
- Tipografías elegantes: combinación de serif (Playfair Display, Cormorant Garamond) para títulos y sans-serif (Lato, Montserrat) para texto
- Animaciones fluidas y elegantes (no excesivas)
- Efectos parallax sutiles
- Glassmorphism en elementos flotantes
- Sombras suaves y naturales
- Bordes redondeados elegantes
- Uso de ilustraciones botánicas de eucalipto como decoración

## 📱 TECNOLOGÍAS REQUERIDAS

- **Frontend**: React 18+ con TypeScript
- **Styling**: Tailwind CSS + Framer Motion para animaciones
- **Backend**: Node.js con Express o Next.js API Routes
- **Base de datos**: SQLite (para simplicidad) o PostgreSQL
- **Autenticación Admin**: JWT con bcrypt
- **Almacenamiento**: LocalStorage para preferencias + Base de datos para registros
- **Responsive**: 100% adaptable a móvil, tablet y desktop

## 📝 FORMULARIO DE CONFIRMACIÓN DE ASISTENCIA (RSVP) - SUPER COMPLETO

El formulario debe ser una experiencia en sí mismo, con múltiples pasos y animaciones elegantes:

### Paso 1: Datos Personales
- Nombre (requerido)
- Apellidos (requerido)
- Email (requerido, con validación)
- Teléfono (requerido)

### Paso 2: Acompañante
- ¿Vienes con acompañante? (Sí/No)
- Si es sí:
  - Nombre del acompañante
  - Apellidos del acompañante
  - Relación (pareja, amigo, familiar)

### Paso 3: Menú y Preferencias
- Tipo de menú principal:
  - 🥩 Carne
  - 🐟 Pescado
  - 🥗 Vegetariano
  - 🌱 Vegano
- Si viene acompañante, selección de menú para el acompañante también
- ¿Tienes alergias o intolerancias alimentarias? (campo de texto)
- Especificar alergias comunes con checkboxes:
  - Gluten
  - Lactosa
  - Frutos secos
  - Mariscos
  - Huevo
  - Otro (especificar)

### Paso 4: Niños
- ¿Llevas niños? (Sí/No)
- Si es sí:
  - ¿Cuántos niños?
  - Por cada niño:
    - Nombre
    - Edad
    - Menú infantil: ¿normal o con restricciones?
    - ¿Necesita trona?

### Paso 5: Información Adicional
- ¿Necesitas transporte al lugar? (Sí/No)
- ¿Tienes alguna necesidad especial? (accesibilidad, etc.)
- Canción que no puede faltar en la fiesta
- Mensaje para los novios (opcional)

### Paso 6: Confirmación
- Resumen de toda la información introducida
- Checkbox de aceptación de datos
- Botón de enviar con animación de confeti al confirmar
- Email de confirmación automático al invitado

### Características del Formulario:
- Barra de progreso animada
- Validación en tiempo real
- Guardado automático del progreso
- Diseño multi-step con transiciones suaves
- Iconos y ilustraciones en cada paso
- Responsive perfecto
- Accesibilidad (ARIA labels, navegación por teclado)

## 🎯 MODELO DE DATOS

### Guest (Invitado)
```typescript
interface Guest {
  id: string;
  nombre: string;
  apellidos: string;
  email: string;
  telefono: string;
  confirmado: boolean;
  fechaConfirmacion?: Date;
  
  // Acompañante
  tieneAcompanante: boolean;
  acompananteNombre?: string;
  acompananteApellidos?: string;
  acompananteRelacion?: string;
  
  // Menú
  menuPrincipal: 'carne' | 'pescado' | 'vegetariano' | 'vegano';
  menuAcompanante?: 'carne' | 'pescado' | 'vegetariano' | 'vegano';
  alergias: string[];
  otraAlergia?: string;
  
  // Niños
  traeNinos: boolean;
  ninos: Child[];
  
  // Adicional
  necesitaTransporte: boolean;
  necesidadesEspeciales?: string;
  cancionSugerida?: string;
  mensajeNovios?: string;
  
  // Metadata
  createdAt: Date;
  updatedAt: Date;
}

interface Child {
  id: string;
  nombre: string;
  edad: number;
  menuEspecial: boolean;
  restricciones?: string;
  necesitaTrona: boolean;
}

interface Wish {
  id: string;
  autorNombre: string;
  mensaje: string;
  foto?: string;
  aprobado: boolean;
  destacado: boolean;
  createdAt: Date;
}

interface Song {
  id: string;
  titulo: string;
  artista: string;
  sugeridoPor: string;
  votos: number;
  aprobado: boolean;
  createdAt: Date;
}
```
