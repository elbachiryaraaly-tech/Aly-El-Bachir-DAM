Crea una página web de portfolio profesional de élite para mi empresa de servicios "Link Plaza", propiedad de Mohamed Salem Nouidjem. Necesito una solución web moderna, completamente responsive y visualmente impactante.

## 🎯 INFORMACIÓN DE LA EMPRESA

**Nombre de la empresa:** Link Plaza  
**Propietario:** Mohamed Salem Nouidjem  
**Tipo de negocio:** Servicios profesionales para el hogar

### Servicios Ofrecidos:
1. **Electricidad Doméstica** - Instalaciones eléctricas completas, reparaciones, mantenimiento preventivo, cuadros eléctricos, iluminación LED, domótica básica
2. **Servicios de Plomería** - Instalación de tuberías, reparación de fugas, instalación de sanitarios, sistemas de agua caliente, destapado de cañerías, mantenimiento preventivo
3. **Instalación de TV y Antena Parabólica** - Montaje de televisores en pared, instalación de antenas satelitales, configuración de decodificadores, cableado profesional
4. **Instalación de Techos para Viviendas** - Techos de chapa, tejas, policarbonato, deck, pérgolas, reparación de techos, impermeabilización

## 🎨 REQUISITOS DE DISEÑO Y TECNOLOGÍA

### Stack Tecnológico (Elige el mejor):
- **Framework:** Next.js 14+ con App Router (TypeScript obligatorio)
- **Estilos:** Tailwind CSS + Framer Motion para animaciones fluidas
- **Componentes:** React Server Components donde sea posible
- **Iconos:** Lucide React (iconos modernos y profesionales)
- **Formularios:** React Hook Form + Zod para validación
- **Fuentes:** Google Fonts - Inter/Montserrat para títulos, Open Sans/Roboto para cuerpo

### Paleta de Colores Profesional:
- **Primario:** Azul profesional (#0F4C81 o similar) - Transmite confianza y profesionalismo
- **Secundario:** Naranja/Dorado (#FF6B35 o #F39C12) - Representa energía y calidez
- **Acento:** Verde (#27AE60) - Para botones de acción y éxito
- **Neutros:** Grises elegantes y blancos puros
- **Degradados:** Usar sutilmente para dar profundidad
