# PROMPT PARA CURSOR - LINK PLAZA - PÁGINA WEB PROFESIONAL DE ÉLITE

Crea una página web profesional de élite para "Link Plaza", un negocio de servicios técnicos especializados. El propietario es Mohamed Salem Nouidjem.

## INFORMACIÓN DEL NEGOCIO

**Nombre del Negocio:** Link Plaza
**Propietario:** Mohamed Salem Nouidjem
**Servicios Ofrecidos:**
1. Electricidad doméstica
2. Servicios de plomería
3. Instalación de TV y antena parabólica
4. Instalación de todo tipo de techos para viviendas

## REQUISITOS TÉCNICOS Y DE DISEÑO

### Stack Tecnológico
- HTML5 semántico y moderno
- CSS3 avanzado con animaciones suaves
- JavaScript vanilla o framework moderno (React/Vue/Next.js)
- Diseño responsive (mobile-first)
- Optimización SEO completa
- Performance optimizada (lazy loading, imágenes optimizadas)
- Accesibilidad WCAG 2.1 AA

### Diseño Visual
- **Estilo:** Moderno, profesional, de élite, limpio y sofisticado
- **Paleta de colores:** 
  - Colores corporativos profesionales (azules eléctricos, grises elegantes, blancos limpios)
  - Acentos en naranja/dorado para destacar llamadas a la acción
  - Contraste alto para legibilidad
- **Tipografía:** Fuentes modernas y profesionales (Google Fonts: Inter, Poppins, o Montserrat)
- **Iconografía:** Iconos profesionales y modernos (Font Awesome, Heroicons, o similar)
- **Imágenes:** Placeholders profesionales con estilo de servicios técnicos (puedes usar Unsplash con keywords relevantes)

- Formulario de contacto funcional (puede usar Formspree, EmailJS, o similar)

- Botones de llamada directa (tel: links)

- Lazy loading de imágenes

#### SEO y Meta Tags
- Meta description optimizada
- Open Graph tags para redes sociales
- Schema.org markup para negocio local

- Minificación de CSS/JS
- Caching headers

- Tablet: 768px - 1024px
- Desktop: 1024px+
- Diseño adaptativo perfecto en todos los dispositivos
- Menú móvil intuitivo
- Botones táctiles de tamaño adecuado
